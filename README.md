# DuAmorPaper Button Renderer

Serviço de renderização geométrica para artes circulares de buttons DuAmorPaper.

Inclui serviço HTTP e servidor MCP, máscaras das áreas visível/dobra/corte, saída PNG a 300 DPI, validação de entrada, autenticação por bearer token e testes.

## Implantação

Consulte `deploy/DEPLOYMENT.md`. Defina `BUTTON_RENDERER_API_KEY` como variável secreta do serviço e não a inclua no repositório.
